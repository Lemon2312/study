Trapped-ion qubit · ¹⁷¹Yb⁺ hyperfine

イオンの中の1ビット |0⟩ / |1⟩

現在主流のイオントラップ方式（IonQ・Quantinuum などが採用する超微細構造（ハイパーファイン）量子ビット）で、1ビットがどこに書き込まれ、どうやって読み出されるのかを、順番に動かして見ていくページです。代表例として ¹⁷¹Yb⁺ の実際の数値を使っています。

速度

    OVERVIEWひとことで言うと

    1個のイオン（¹⁷¹Yb⁺）の最外殻電子が、基底状態の中のわずかに異なる2つのエネルギー準位のどちらにいるか、で 0 と 1 を表します。両者の差は 12.6 GHz（マイクロ波）しかなく、どちらも光を出して崩壊しないので非常に長く量子状態を保てます。読み出しでは、片方の準位（|1⟩）にだけ共鳴する紫外レーザーを当てます。|1⟩ なら電子が何百回も励起と放出を繰り返してイオンが光り、|0⟩ なら暗いままです。光子を数えて「光った／光らない」で 0/1 を決めます。

    STEP 1 · 捕まえるイオンを宙に浮かせる

    真空槽の中で中性 Yb 原子を加熱して飛ばし、399 nm（中性原子の共鳴）と 369 nm（電離限界を超える2段目）のレーザーで電子を1個はぎ取って Yb⁺ にします。電荷を持ったイオンは電場で捕まえられます。

    静電場だけでは3次元の安定点を作れない（アーンショウの定理）ため、20〜40 MHz 程度の高周波（RF）電圧で鞍型ポテンシャルを高速に反転させ、時間平均で中心に戻す力を作ります（ポール・トラップ）。軸方向は端の電極の直流電圧で弱く閉じ込めるので、冷えたイオンは数 µm 間隔の一列に並びます。最近の装置は、電極を平面に描いた表面電極トラップ（チップ）が主流です。

    STEP 2 · 表現|0⟩ と |1⟩ の定義

    Yb⁺ は最外殻（6s）に電子1個だけを持つ水素のようなイオンです。¹⁷¹Yb の原子核はスピン I = ½ を持つので、基底状態 ²S₁/₂ は電子スピンとの結合で F = 0 と F = 1 の2つの超微細準位に分かれます。

    |0⟩ ≡ |F=0, mF=0⟩、|1⟩ ≡ |F=1, mF=0⟩。この2つは磁場の1次の影響を受けない「時計遷移」の組で、残るのは 310.8 Hz/G² の2次効果だけです。だから磁場の揺らぎに強く、コヒーレンス時間は通常でも秒単位、磁場遮蔽と動的デカップリングを組み合わせた実験では1時間を超えた報告もあります。量子ビットは一般の重ね合わせ α|0⟩ + β|1⟩ をとることができ、ブロッホ球上の1点として表されます。

    STEP 3 · 初期化光ポンピングで |0⟩ に揃える

    369 nm 光に電気光学変調器（EOM）で 2.105 GHz のサイドバンドを付け、F=1 → ²P₁/₂ F′=1 に共鳴させます。F′=1 から自然放出すると約 1/3 の確率で F=0 に落ちます。F=0 は 12.6 GHz 以上離調しているのでもう光を吸収せず、そこに溜まります（暗状態）。散乱 n 回後に F=1 に残る確率は約 (2/3)ⁿ で、20 回ほど、時間にして数 µs で 99.9% 以上が |0⟩ になります。

    STEP 4 · 操作重ね合わせを作る

    12.6 GHz のマイクロ波、または 355 nm パルスレーザー2本の周波数差を 12.6 GHz に合わせた誘導ラマン遷移で、|0⟩ と |1⟩ の間を共鳴的に駆動します。ブロッホ球上ではベクトルが回転し、回転角 θ はパルスの強さ×時間（パルス面積）で決まります。θ = π/2 で等しい重ね合わせ、π で反転です。ラマン光は2本のビームの波数差でイオンの振動とも結合できるので、2量子ビットゲートにも使われます。

    STEP 5 · 測定状態依存蛍光による読み出し

    369.5 nm の検出光を ²S₁/₂ F=1 → ²P₁/₂ F′=0 に正確に共鳴させて当てます。選択則により F′=0 は F=1 にしか戻れない（F′=0 → F=0 は禁制）ので、|1⟩ にいる電子は「吸収→ 8 ns で放出」を延々と繰り返す閉じたサイクルに入ります。1 µs あたり数個〜十数個の光子を全方向に放出し、そのうち対物レンズ（NA 0.3〜0.6）が拾える数 % が光電子増倍管（PMT）、アバランシェフォトダイオード、または EMCCD カメラに届きます。100〜300 µs の検出窓で、明るいイオンからは平均 10〜30 カウントほどが得られます。

    一方 |0⟩（F=0）から最も近い遷移は F′=1 で、検出光から 14.7 GHz 離れています。自然幅 Γ/2π ≈ 19.6 MHz の約 750 倍も離調しているので、ほとんど光を吸収しません。カウントは迷光や暗計数による 0〜1 個程度です。こうしてカウント数の分布は「平均 ~0.1 付近」と「平均 ~10 以上」の2つのポアソン分布にきれいに分かれ、しきい値（例えば 2 カウント以上なら 1）で判定します。

    量子力学的には、検出光を当てた瞬間に重ね合わせ α|0⟩+β|1⟩ は |0⟩ か |1⟩ のどちらかに射影され、その確率は |α|²、|β|² です。1回の測定で得られるのは 0 か 1 の1ビットだけなので、同じ状態準備と測定を数百〜数千回繰り返して確率を推定します。

    誤差の主な原因は3つです。(1) |1⟩ の電子が F′=1 を 2.1 GHz 離調で非共鳴励起され、F=0 に落ちて途中で暗くなる。(2) |0⟩ の電子が 14.7 GHz 離調で励起されて明るくなる。(3) ²P₁/₂ から 0.5% の確率で準安定な ²D₃/₂ に落ちて暗くなる（935 nm のリポンプ光で ³D[3/2]₁/₂ に汲み上げて基底状態に戻す）。集光効率を上げて検出窓を短くするほど (1)(2) は減ります。この方式の状態準備＋測定（SPAM）忠実度はおおむね 99.9% 以上です。

    VARIANTSほかの方式との違い

    Quantinuum の H1/H2 は ¹⁷¹Yb⁺ を量子ビットに使い、冷却用に ¹³⁸Ba⁺ を混ぜています。新しい世代（Quantinuum Helios など）では ¹³⁷Ba⁺ の超微細量子ビットへの移行が進んでいます。Ba⁺ では測定の前に 1762 nm のレーザーで |1⟩ だけを寿命約 30 秒の ²D₅/₂ へ「棚上げ（shelving）」してから 493 nm の蛍光で読むので、非共鳴励起による漏れがほぼなくなり、さらに高い読み出し忠実度が得られます。⁴⁰Ca⁺ を使う光学量子ビット（S₁/₂ と D₅/₂ の間、729 nm）も同じ考え方で、D₅/₂ が暗状態、S₁/₂ が 397 nm で光る明状態になります。どの方式でも「片方の状態だけを閉じたサイクルで光らせて光子を数える」という読み出しの原理は共通です。

    アニメーションは時間を大きく引き延ばしています（光ポンピングは実際には数 µs、検出窓は数百 µs、RF の反転は 1 周期 30 ns 程度）。測定シミュレーションのカウント統計は典型的な実験値に合わせたポアソン過程のモデルです。
