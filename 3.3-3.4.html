古典のゲート と 量子ゲート3.4（pp.91–92）

  • 量子ビットの状態と、それを測定できることは分かった。しかし、これだけでは計算できない
  • 古典コンピュータは、ビット演算を行う ゲート（AND, OR, XOR, NOT など）でビットの状態を変化させて計算する
  • 古典コンピュータのゲートに相当するものが 量子ゲート
  • 量子ゲートの操作にあたるものを ユニタリ発展 という
古典：ビット 0 / 1 を書き換える
量子：量子状態 |φ⟩ を ユニタリ行列 U で U|φ⟩ に変える

ユニタリ発展定義（p.92）

量子状態 |φ⟩ は、2×2 ユニタリ行列 U を使って U|φ⟩ という量子状態に変化する。このような量子状態の変化を ユニタリ発展（unitary evolution）という
第2章の復習：ユニタリ行列 とは U†U = I が成り立つ行列
U† は U の転置の複素共役（随伴）、I は単位行列
量子コンピュータは、ユニタリ発展を行う 回路を実装 することで、量子ビットの状態を変化させ、計算できる
第3章 量子コンピュータの基本ルール ／ 3.4 ビットの状態を変化させる「量子ゲート」

巨大なユニタリ発展も高速にp.92

  • ユニタリ発展に使うユニタリ行列のサイズが 指数関数的に巨大 になっても、量子コンピュータの計算時間への影響は 古典コンピュータほど大きくならない
  • そのため、量子コンピュータは指数関数的に巨大なユニタリ発展を 高速に 行える
⚠ ただし、あらゆる行列計算を高速化できる訳ではない。

第3章 量子コンピュータの基本ルール ／ 3.4.1

ユニタリ発展させても、量子状態のまま3.4.1（pp.92–93）

U|φ⟩ が量子状態にならないと、この定義は意味がない。
|φ⟩ を量子状態、U をユニタリ行列として確かめよう

⟨Uφ|Uφ⟩= (Uφ)†(Uφ)内積の定義
= φ†U†Uφ(AB)† = B†A†
= φ†Iφ = φ†φU†U = I（ユニタリ）
= ⟨φ|φ⟩ = 1|φ⟩ は量子状態
内積による量子状態の定義（p.87）を満たすので U|φ⟩ も量子状態。
→ ユニタリ行列 U は「量子状態 → 量子状態」の関数と見られる
第3章 量子コンピュータの基本ルール ／ 3.4.2

任意のユニタリ発展は、ハードウェアとして実装可能3.4.2（p.93）

  • 任意のユニタリ発展を近似的に実装できる ことが、理論的に分かっている
  • これは ソロベイ－キタエフの定理（Solovay–Kitaev theorem）として知られている
  • 詳しい説明は本書の範囲を越える（巻末の参考文献 [8][9][10]）
イメージ：決まった少しの種類のゲート を何個もつなげると、どんなユニタリ発展にも、いくらでも近づける
右の例：使えるのは G（約57.3°回す回転）だけ。
G を何回かければ目標に一番近いか探す。使える個数を増やすほど、ずれが小さくなる
※ イメージ図（教科書外）。実際の定理は H・T のような少数のゲートの組み合わせで、効率よく近似できることを示す
第3章 量子コンピュータの基本ルール ／ 3.4.3

ユニタリ発展の可逆性3.4.3（p.93）

  • ユニタリ行列は 必ず逆行列を持つ（U†U = I なので U−1 = U†）
  • そのため、U|φ⟩ を U−1 でユニタリ発展させると
U−1U|φ⟩ = |φ⟩
  • となり、|φ⟩ に戻る。状態の変化に対して、元に戻す変化が可能 であることを 可逆（reversible）という
そのため、任意のユニタリ発展は可逆
いくつ続けても、逆順に U−1 をかければ元通り
第3章 量子コンピュータの基本ルール ／ 3.4.3

古典回路と比べてみる：AND図3.4（p.93）

  • 量子回路の可逆性は、古典回路と大きく異なる点
  • AND は 2個のビットを入力し、1個の出力 を得る操作。すべての入力が 1 のときに出力が 1、それ以外は 0
🤔 考えてみよう：出力だけ を見て、入力を元に戻せる？

→ AND は 元に戻せない（ユニタリ発展とは違う）
