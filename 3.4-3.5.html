ユニタリ発展定義（p.92）

量子状態 |φ⟩ は、2×2 ユニタリ行列 U を使って U|φ⟩ という量子状態に変化する。このような量子状態の変化を ユニタリ発展（unitary evolution）という

量子コンピュータは、ユニタリ発展を行う 回路を実装 することで、量子ビットの状態を変化させ、計算できる

任意のユニタリ発展は、ハードウェアとして実装可能3.4.2（p.93）

第3章 量子コンピュータの基本ルール ／ 3.4.3

ユニタリ発展の可逆性3.4.3（p.93）

  • ユニタリ行列は 必ず逆行列を持つ（U†U = I なので U−1 = U†）
  • そのため、U|φ⟩ を U−1 でユニタリ発展させると
U−1U|φ⟩ = |φ⟩
  • となり、|φ⟩ に戻る。状態の変化に対して、元に戻す変化が可能 であることを 可逆（reversible）という
そのため、任意のユニタリ発展は可逆
いくつ続けても、逆順に U−1 をかければ元通り
※ R(θ)・S・H・X は例（S は |1⟩ の係数に i をかけるゲート）。紫の線が通った道すじ

区別できる例3.5・3.5.1（pp.94–95）

量子状態は測定しないと分からない。ただ、2つの量子状態で |0⟩・|1⟩ を測定する確率が 同じになるケース がある

|+⟩ =1√2(|0⟩ + |1⟩)　と　|−⟩ =1√2(|0⟩ − |1⟩)
→ どちらも確率 1/2 で |0⟩、1/2 で |1⟩。このまま測定しても区別できない
※ |+⟩, |−⟩ はこの資料での略記
第4章の アダマール行列 H =1√2111−1 でユニタリ発展させると、測定で得る確率を変えられる
H|+⟩ = |0⟩H|−⟩ = |1⟩
H をかけた後で測定すると、|+⟩ は 確率 1 で |0⟩、|−⟩ は 確率 1 で |1⟩ → 区別できる！

第3章 量子コンピュータの基本ルール ／ 3.5.3 区別できない理由

|φ⟩ と z|φ⟩（|z| = 1）3.5.3（p.97）

  • 量子状態 |φ⟩ = a|0⟩ + b|1⟩ は、|0⟩ を得る確率が |a|²、|1⟩ を得る確率が |b|²

測定する確率を内積で表す定理3.1（pp.97–98）

準備として、測定する確率を 内積 を使って表す。量子状態 |φ⟩ = a|0⟩ + b|1⟩ に対し

⟨0|φ⟩= ⟨0|(a|0⟩ + b|1⟩) = a⟨0|0⟩ + b⟨0|1⟩分配
= a1010 + b1001ベクトルで

量子状態 |φ⟩ = a|0⟩ + b|1⟩ について、次の式が成り立つ。

第3章 量子コンピュータの基本ルール ／ 3.5.3 区別できない理由

ユニタリ発展させても区別できない定理3.2（pp.98–99）

z|φ⟩ をユニタリ発展させたものは、ユニタリ行列 U を使って Uz|φ⟩ と書ける。定理3.1 と第2章の定理2.7 を使って |0⟩ を得る確率を求めると

|⟨0|Uzφ⟩|² = |⟨0|Uφ⟩|²
式変形のイメージ（補足）：z はただの数なので外に出せる
|⟨0|Uzφ⟩|² = |z⟨0|Uφ⟩|² = |z|²|⟨0|Uφ⟩|² = |⟨0|Uφ⟩|²
  • U|φ⟩ と Uz|φ⟩ で |0⟩ を得る確率が同じ → ユニタリ発展させても区別できない（|1⟩ も同様）
|z| = 1 を満たす複素数 z に対して、量子状態 |φ⟩ と z|φ⟩ は 区別できない（同一の量子状態）
どんなユニタリ発展や測定を行っても区別できない量子状態は、同一の量子状態 と考える。数式では別の表現でも、実は同一の量子状態の場合があるので、同一かどうか判定するときは注意
前節の例に当てはめると：|φ⟩ =1√2(|0⟩ + |1⟩)、z = −1 とすると z|φ⟩ = −1√2(|0⟩ + |1⟩)
→ 定理3.2 により 区別できない
